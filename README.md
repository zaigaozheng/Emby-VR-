# rPlayer（Emby）使用说明

**适用版本：1.6 · Android 8.1 或更新版本**

rPlayer（Emby）是安卓 Emby 的外部播放器转接工具。你在 Emby 里选中影片后，它会把播放地址交给原版 rPlayer，由原版 rPlayer 播放并提供 VR 模式。

## 安装

1. 手机上先安装**原版 rPlayer 1.1.2**和**安卓 Emby App**。已经安装的可以直接继续。
2. 在手机上打开 `rPlayer-Emby.apk` 并安装。如果系统提示需要授权，按提示允许当前文件管理器或浏览器安装此 APK。
3. 在桌面点一次粉色图标的 **rPlayer（Emby）**，看到「转接入口已启用」后点确定。

## 从 Emby 播放 VR 视频

1. 打开**安卓 Emby App**，启用外部播放器，或从影片菜单选择「使用外部播放器播放」。
2. 打开要看的影片，在播放器列表里选择 **rPlayer（Emby）**。
3. 手机会进入原版 rPlayer 的播放界面。按影片格式在 rPlayer 内选择相应的 VR 模式。

## 常见问题

- **桌面点开后只有提示？** 这是转接包的启用提示。从 Emby 选片时用 **rPlayer（Emby）**，平时要打开播放器或播放本地文件时用**原版 rPlayer**。
- **Emby 的列表里找不到它？** 先确认安装的是 `rPlayer-Emby.apk`，再从桌面打开一次 **rPlayer（Emby）**，回到安卓 Emby 重新打开外部播放器列表。
- **能播放但不能快进，或总时长不显示？** 转接包会优先使用支持跳转的原文件串流。如果服务器只提供实时转码串流，快进和总时长仍可能受限。
- **发给别人需要哪些文件？** 对方已有原版 rPlayer 时，只需发 `rPlayer-Emby.apk`。对方还没有原版 rPlayer 时，需要先安装原版。
